# ЛР2 — Построение структуры смежности

## Задача

Построить структуру смежности для треугольной сетки на четырёхугольной области
с вершинами (0, 0), (10, 0), (8, 10), (0, 7) и разбиением 15×10.

## Описание работы программы

### 1. Генерация сетки

Сетка строится на четырёхугольнике с помощью билинейного отображения.
Параметрическое пространство `[0,1]×[0,1]` отображается в физические координаты:

```
x(s,t) = (1-s)(1-t)·x₀ + s(1-t)·x₁ + s·t·x₂ + (1-s)t·x₃
y(s,t) = (1-s)(1-t)·y₀ + s(1-t)·y₁ + s·t·y₂ + (1-s)t·y₃
```

Каждый прямоугольник параметрического пространства делится на 2 треугольника.
Итого: (15+1)×(10+1) = 176 узлов, 15×10×2 = 300 элементов.

### 2. Формат файла сетки

```
<количество узлов>
x₀ y₀
x₁ y₁
...
<количество элементов>
n₀ n₁ n₂
...
```

### 3. Динамическая структура смежности

Для каждого узла хранится множество (`std::set`) смежных узлов.
Два узла считаются смежными, если они принадлежат одному элементу.
Множество обеспечивает уникальность и отсортированность соседей.

### 4. Статическая структура смежности (формат CSR)

Динамическая структура преобразуется в компактный формат:
- `xadj[i]` — индекс начала списка соседей узла `i` в массиве `adjncy`
- `adjncy` — сплошной массив номеров смежных узлов

Преимущество: экономия памяти и быстрый доступ.

### 5. Вывод

Структура смежности записывается в файл `adjacency.txt`.

## Результаты

- 176 узлов, 300 элементов
- Степени узлов: от 2 (угловые) до 6 (внутренние)
- Файлы: `mesh.txt`, `adjacency.txt`
