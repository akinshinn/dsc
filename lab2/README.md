# ЛР2 — Построение структуры смежности

## Задача

Построить структуру смежности для сетки на четырёхугольной области
с вершинами (0, 0), (10, 0), (8, 10), (0, 7) и разбиением 15×10.

## Типы сеток (из ЛР3, Семестр 1)

Программа поддерживает все 4 типа сеток для четырёхугольника:
- **Тип 1** — четырёхугольные элементы (4 узла)
- **Тип 2** — треугольные, диагональ `/` (3 узла, 2 треугольника на ячейку)
- **Тип 3** — треугольные, диагональ `\` (3 узла, 2 треугольника на ячейку)
- **Тип 4** — треугольные через центр (3 узла, 4 треугольника на ячейку)

По умолчанию используется тип 2. Тип задаётся параметром `type` в `generate_quad_mesh`.

## Описание работы программы

### 1. Генерация сетки

Узлы строятся билинейной интерполяцией по 4 вершинам.
Элементы создаются в зависимости от типа сетки.
Для типа 4 добавляются центральные узлы ячеек.

### 2. Формат файла сетки

```
<количество узлов>
x₀ y₀
x₁ y₁
...
<количество элементов>
<кол-во узлов в элементе> n₀ n₁ ...
...
```

### 3. Динамическая структура смежности

Для каждого узла хранится множество (`std::set`) смежных узлов.
Два узла смежны, если они принадлежат одному элементу.

### 4. Статическая структура смежности (формат CSR)

- `xadj[i]` — индекс начала списка соседей узла `i` в `adjncy`
- `adjncy` — сплошной массив номеров смежных узлов

## Результаты (тип 2)

- 176 узлов, 300 элементов
- Степени узлов: от 2 (угловые) до 6 (внутренние)
