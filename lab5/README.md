# ЛР5 — Оптимизация нумерации узлов обратным методом Катхилла-МакКи (RCM)

## Задача

Перенумеровать узлы сетки из ЛР2 методом RCM для уменьшения
полуширины ленты и оболочки (профиля) матрицы.
Поддерживаются все типы сеток из ЛР3 (Семестр 1).

## Типы сеток

- **Тип 1** — четырёхугольные элементы (4 узла)
- **Тип 2** — треугольные, диагональ `/` (по умолчанию)
- **Тип 3** — треугольные, диагональ `\`
- **Тип 4** — треугольные, 4 через центр

## Алгоритм RCM

1. Найти псевдопериферийный узел (ЛР4).
2. BFS от него, соседи добавляются по возрастанию степени (алгоритм CM).
3. Развернуть полученный порядок (reverse → RCM).

## Параметры матрицы

- **Полуширина ленты** — `max|i - j|` по всем связям
- **Оболочка (профиль)** — `Σᵢ (i - min_j(i))`

## Результаты (тип 2)

| Параметр | До RCM | После RCM | Улучшение |
|----------|--------|-----------|-----------|
| Полуширина ленты | 17 | 11 | 35.3% |
| Оболочка (профиль) | 2725 | 1540 | 43.5% |
