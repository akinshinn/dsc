# ЛР5 — Оптимизация нумерации узлов обратным методом Катхилла-МакКи (RCM)

## Задача

Перенумеровать узлы сетки из ЛР2 методом RCM для уменьшения
полуширины ленты и оболочки (профиля) матрицы.

## Описание работы программы

### 1. Алгоритм Катхилла-МакКи (CM)

BFS-обход от начального узла, где соседи добавляются в порядке
возрастания степени:

1. Начать с псевдопериферийного узла (найденного в ЛР4).
2. Поместить его в очередь и в результирующий порядок.
3. Для каждого узла из очереди: собрать непосещённых соседей,
   отсортировать по возрастанию степени, добавить в очередь.
4. Повторять до обхода всех узлов.

### 2. Обратный метод (RCM)

Порядок, полученный алгоритмом CM, разворачивается (reverse).
Это даёт лучшие результаты для ленточных матриц —
доказано теоретически и подтверждено практикой.

### 3. Параметры матрицы

- **Полуширина ленты** — `max|i - j|` по всем ненулевым элементам `(i, j)`
- **Оболочка (профиль)** — `Σᵢ (i - min_j(i))`, где `min_j(i)` — минимальный
  индекс столбца в `i`-й строке

Чем меньше эти параметры, тем эффективнее ленточные методы решения СЛАУ.

### 4. Применение перенумерации

После получения нового порядка узлов:
- Узлы пересортировываются в новом порядке
- Номера узлов в элементах обновляются через таблицу соответствия

### 5. Вывод

- `mesh_original.txt` — исходная сетка
- `mesh_rcm.txt` — перенумерованная сетка
- `params.txt` — сравнение параметров матрицы

## Результаты

| Параметр | До RCM | После RCM | Улучшение |
|----------|--------|-----------|-----------|
| Полуширина ленты | 17 | 11 | 35.3% |
| Оболочка (профиль) | 2725 | 1540 | 43.5% |

Начальный узел для RCM: 160 (координаты: 0.00, 7.00).
