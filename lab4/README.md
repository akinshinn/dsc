# ЛР4 — Поиск начального узла

## Задача

Найти начальный (псевдопериферийный) узел для сетки из ЛР2.
Вывести корневую структуру уровней для найденного узла.

## Описание работы программы

### 1. Что такое псевдопериферийный узел

Периферийный узел — узел, дающий максимальную глубину BFS-дерева.
Точный поиск периферийного узла дорог, поэтому используется
приближённый алгоритм, находящий псевдопериферийный узел.

### 2. Алгоритм Джорджа—Лю

1. Выбрать произвольный узел `r` (например, 0).
2. Построить корневую структуру уровней от `r`.
3. На последнем уровне найти узел `v` с минимальной степенью.
4. Построить корневую структуру уровней от `v`.
5. Если глубина увеличилась — присвоить `r = v` и повторить с шага 2.
6. Если глубина не увеличилась — `v` является псевдопериферийным узлом.

### 3. Зачем нужен псевдопериферийный узел

Псевдопериферийный узел используется как стартовый узел для
алгоритма Катхилла-МакКи (RCM), который оптимизирует нумерацию
узлов для уменьшения ширины ленты матрицы.

### 4. Вывод

- `levels_start.txt` — структура уровней от найденного узла
- `levels_node0.txt` — структура уровней от узла 0 (для сравнения)

## Результаты

- Начальный узел: 0, глубина: 16
- После 1-й итерации: узел 15 (10.00, 0.00), глубина: 26
- После 2-й итерации: узел 160 (0.00, 7.00), глубина: 26 — не увеличилась
- Найденный псевдопериферийный узел: **160** (координаты: 0.00, 7.00)
- Глубина BFS от найденного узла: 26 (против 16 от узла 0)
