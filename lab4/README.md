# ЛР4 — Поиск начального узла

## Задача

Найти начальный (псевдопериферийный) узел для сетки из ЛР2.
Поддерживаются все типы сеток из ЛР3 (Семестр 1).

## Типы сеток

- **Тип 1** — четырёхугольные элементы (4 узла)
- **Тип 2** — треугольные, диагональ `/` (по умолчанию)
- **Тип 3** — треугольные, диагональ `\`
- **Тип 4** — треугольные, 4 через центр

## Алгоритм Джорджа—Лю

1. Выбрать произвольный узел `r` (например, 0).
2. Построить корневую структуру уровней от `r`.
3. На последнем уровне найти узел `v` с минимальной степенью.
4. Построить структуру уровней от `v`.
5. Если глубина увеличилась — повторить с шага 2.
6. Иначе `v` — псевдопериферийный узел.

## Результаты (тип 2)

- Найденный узел: 160 (координаты: 0.00, 7.00)
- Глубина: 26 (против 16 от узла 0)

g++ -std=c++17 -O2 -o lab4 lab4.cpp
