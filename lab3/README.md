# ЛР3 — Построение корневой структуры уровней

## Задача

Построить корневую структуру уровней для сетки из ЛР2,
начиная от узла 0. Поддерживаются все типы сеток из ЛР3 (Семестр 1).

## Типы сеток

- **Тип 1** — четырёхугольные элементы (4 узла)
- **Тип 2** — треугольные, диагональ `/` (по умолчанию)
- **Тип 3** — треугольные, диагональ `\`
- **Тип 4** — треугольные, 4 через центр

## Алгоритм

Обход в ширину (BFS) от корневого узла:

1. Корневой узел помещается в очередь с уровнем 0.
2. Извлекается узел из очереди, добавляется в свой уровень.
3. Непосещённые соседи получают уровень +1, помещаются в очередь.
4. Повторяется, пока очередь не пуста.

## Результаты (тип 2)

- Корневой узел: 0
- Количество уровней: 16

g++ -std=c++17 -O2 -o lab3 lab3.cpp
