# ЛР3 — Построение корневой структуры уровней

## Задача

Построить корневую структуру уровней для сетки из ЛР2,
начиная от узла 0 (нумерация с нуля, соответствует «узлу 1» в задании).

## Описание работы программы

### 1. Повторное использование функций из ЛР2

Программа включает функции генерации сетки, записи/чтения,
а также построения динамической и статической структур смежности.

### 2. Алгоритм построения корневой структуры уровней

Используется обход в ширину (BFS) от корневого узла:

1. Поместить корневой узел в очередь, присвоить ему уровень 0.
2. Извлечь узел из очереди, добавить его в соответствующий уровень.
3. Все непосещённые соседи получают уровень на 1 больше и добавляются в очередь.
4. Повторять, пока очередь не пуста.

Результат — набор уровней, где уровень `k` содержит все узлы
на расстоянии `k` рёбер от корня.

### 3. Структура данных

```cpp
struct LevelStructure {
    int root;                            // корневой узел
    std::vector<std::vector<int>> levels; // уровни: levels[k] — узлы уровня k
    std::vector<int> level_of;            // level_of[i] — номер уровня узла i
};
```

### 4. Вывод

Структура уровней записывается в файл `levels.txt` с указанием
количества узлов на каждом уровне и их номеров.

## Результаты

- Корневой узел: 0 (вершина (0, 0))
- Количество уровней: 16
- Первый уровень: 1 узел (корень)
- Последний уровень: 11 узлов
